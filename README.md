# Research Repository - SithCare 

## Purpose
This repository acts as the central host for all fact-finding and research artifacts generated during the analysis phase of the SithCare project. It contains the foundational evidence required for the Software Requirements Specification (SRS).

## Contents Structure
The repository is organized into the following directories based on the required fact-finding techniques:
* `/literature-review`: Contains literature review notes and academic references supporting the project background.
* `/competitive-analysis`: Stores feature comparison matrices, screenshots, and summaries of gaps in existing solutions.
* `/interviews`: Contains structured interview guides, client interview transcripts, and key findings.
* `/surveys`: Includes survey instruments, anonymized responses, and statistical summaries.

## Tooling Required
To open, view, and contribute to the files in this repository, the following tools are required:
* **Markdown Editor:** Required for reading and editing `.md` files (e.g., VS Code, Typora).
* **PDF Viewer:** Required for viewing exported research documents or scanned observation protocols.
* **Spreadsheet Software:** (e.g., MS Excel, Google Sheets) for viewing survey data exports or competitive analysis matrices.
